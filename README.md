# 手写数字识别（MNIST）—— AI 入门实战教程

> 一份面向**零基础人工智能初学者**的完整项目教程：从安装环境开始，到训练出自己的神经网络，最后做出一个「在屏幕上写数字、AI 来猜」的小程序。
> 全教程共 11 步，每一步都是**统一格式**的文档 + **完整可运行**的代码 + 自检清单，跟着做即可。

---

## 为什么选这个项目？

MNIST 手写数字识别被称为「AI 界的 Hello World」——所有学编程的人第一行代码都是 `print("Hello World")`，而几乎所有学 AI 的人第一个项目都是 MNIST。原因：

| 优点 | 说明 |
| :--- | :--- |
| 数据小 | 全部数据只有 10 几 MB，下载快、读取快 |
| 问题直观 | 输入一张 28×28 的数字图片，输出 0~9 之一，人人都能理解 |
| 训练快 | 纯 CPU 也能在几分钟内完成训练，不需要显卡 |
| 流程完整 | 数据 → 预处理 → 建模 → 训练 → 评估 → 部署，AI 项目的完整闭环都能走一遍 |
| 有成就感 | 最后你可以亲手写一个数字，让 AI 猜中它，肉眼可见的成果 |

## 你将学到什么？

- ✅ Python 环境搭建与包管理（venv、pip）
- ✅ 深度学习框架 **PyTorch** 的基本用法
- ✅ 数据集、张量（Tensor）、归一化、批处理（Batch）等核心概念
- ✅ 神经网络原理：全连接层、激活函数、卷积层、池化层
- ✅ 训练循环：损失函数、优化器、反向传播、学习率
- ✅ 模型评估：混淆矩阵、错误样本分析
- ✅ 模型保存、加载与推理（inference）
- ✅ 一个可以拿去玩的成果：手写数字识别 Demo
- ✅ **服务化部署**：用 FastAPI 把模型做成 HTTP 接口，配一个能画数字的网页前端

## 环境要求

- 操作系统：Windows / macOS / Linux 均可（教程命令以 Windows 为主，其他系统差异会在文档中说明）
- Python：3.9 ~ 3.12（太老的版本不支持新 PyTorch）
- 硬件：**纯 CPU 即可**，不需要显卡，不需要任何云服务
- 基础：会打开终端、会复制粘贴命令即可，不需要任何 AI 基础
- **磁盘空间**：约 2 GB（PyTorch 依赖约 1.5 GB，MNIST 数据约 65 MB）
- **网络**：需要联网下载依赖和数据。国内网络建议全程使用镜像源（见下方「快速开始」），MNIST 数据约 12 MB

## 本教程的通用约定（每一步都适用）

初学者最容易卡住的不是算法，而是环境。请记住这三条：

1. **每次打开新终端，都要先激活虚拟环境**：`.venv\Scripts\Activate.ps1`（macOS/Linux：`source .venv/bin/activate`）。命令行开头出现 `(.venv)` 才算激活成功
2. **所有命令都在项目根目录执行**：即包含 `README.md` 的 `手写数字识别教程` 文件夹。不在就 `cd 手写数字识别教程`
3. **每篇步骤文档的「动手实践」开头都有「💻 运行前确认」**，照着确认一遍再动手

> 如果运行脚本时报 `ModuleNotFoundError: No module named 'torch'`，99% 是**忘了激活虚拟环境**，而不是没安装成功——回到第 1 条。

## 快速开始

```bash
# 1. 打开终端（Windows 按 Win+R 输入 powershell），进入本项目目录
cd 手写数字识别教程

# 2. 创建虚拟环境（把依赖隔离在本项目内，干净卫生）
python -m venv .venv

# 3. 激活虚拟环境（Windows PowerShell；cmd 用 .venv\Scripts\activate.bat）
.venv\Scripts\Activate.ps1

# 4. 安装依赖（国内用户加 -i 用清华镜像，速度快很多）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

装好后，打开 [第 1 步](md/step-01-环境准备.md) 开始你的 AI 之旅吧！

> 📌 上面的命令装的是前 10 步的依赖。做到[第 11 步（网页部署）](md/step-11-FastAPI网页部署.md)时，再额外执行：
> `pip install -r requirements-web.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

## 学习建议

1. **按顺序来**：每一步都依赖上一步，跳步会卡壳；每步做完「完成自检」再进下一步
2. **动手为主**：代码要亲手敲（或复制后逐行读懂）并跑起来，光看不练学不会
3. **大胆修改**：教程会明确告诉你「可以改哪里、改了会怎样」，多试错进步最快
4. **遇到报错别慌**：先读报错信息的**最后一行**，再去本步的「常见问题」里找答案
5. **输出你的笔记**：每步结尾用自己的话写三句小结，讲给别人听是最好的学习方式
