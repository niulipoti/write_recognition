### 10.1 全流程回顾：你走过的每一步

把前面 9 步串起来，就是所有 AI 项目的标准流程：

```
┌─────────────────────────────────────────────────────────┐
│  ① 环境准备（第 1 步）                                    │
│     Python、venv、PyTorch                                │
├─────────────────────────────────────────────────────────┤
│  ② 认识数据（第 2 步）                                    │
│     MNIST：6 万训练 + 1 万测试，28×28 灰度图              │
├─────────────────────────────────────────────────────────┤
│  ③ 数据预处理（第 3 步）                                  │
│     转张量 → 归一化 → 划分 train/val/test → DataLoader    │
├─────────────────────────────────────────────────────────┤
│  ④ 构建模型（第 4 步）                                    │
│     MLP：784 → 128 → 64 → 10（109,386 参数）             │
├─────────────────────────────────────────────────────────┤
│  ⑤ 训练模型（第 5 步）                                    │
│     五步曲：清梯度→前向→损失→反向→更新；验证准确率 ~97%   │
├─────────────────────────────────────────────────────────┤
│  ⑥ 评估模型（第 6 步）                                    │
│     混淆矩阵、逐类准确率、错误样本分析                     │
├─────────────────────────────────────────────────────────┤
│  ⑦ 保存与加载（第 7 步）                                  │
│     state_dict、推理函数（eval + no_grad + softmax）      │
├─────────────────────────────────────────────────────────┤
│  ⑧ 实际应用（第 8 步）                                    │
│     画板 Demo：推理数据与训练数据同分布                    │
├─────────────────────────────────────────────────────────┤
│  ⑨ 模型进阶（第 9 步）                                    │
│     CNN：卷积+池化，参数减半、准确率 98%+                 │
└─────────────────────────────────────────────────────────┘
```

**换任何任务（识别猫狗、预测房价、文本分类），流程完全一样，变的只是数据和模型。** 你已经掌握了 AI 项目的方法论，而不仅仅是一个 Demo。

### 10.3 进阶挑战任务（按难度排序）

**⭐ 热身**

1. 让画板 Demo 加载 `model_cnn.pth`（第 9 步成果），对比两种模型的识别手感
2. 给画板加一个按键 `r`：显示最近 3 次识别的历史
3. 把训练改成 10 个 epoch，观察 MLP 和 CNN 的过拟合速度差异

**⭐⭐ 巩固**

4. **Fashion-MNIST**：torchvision 里现成的「时尚版 MNIST」（衣服鞋子 10 类），只需把 `datasets.MNIST` 换成 `datasets.FashionMNIST`。跑通全流程——你会发现所有代码几乎不用改
5. 实现**数据增强**：给训练数据加随机旋转/平移（`transforms.RandomRotation`），观察模型鲁棒性提升
6. 给 CNN 加 **Dropout** 层（`nn.Dropout(0.5)` 放在全连接层之间），对抗过拟合

**⭐⭐⭐ 挑战**

7. **Kaggle Digit Recognizer**：去 kaggle.com 参加同名比赛，用本教程的 CNN 对竞赛测试集（2.8 万张）生成预测 CSV 提交，看看自己的排名——这是最真实的「AI 实战」
8. 用手机拍一张手写数字照片，自己写预处理（裁剪、二值化、居中）让模型认出来——把第 8 步的「完美条件」推进到「真实世界」
9. 把训练好的模型用 **Flask/FastAPI 做成网页**：浏览器里画画，服务器返回识别结果

### 10.4 下一步学习路线

你已经具备了最关键的「动手能力」。接下来三条主线：

**主线一：补理论基础（理解为什么）**

| 资源 | 特点 |
| :--- | :--- |
| 吴恩达《Machine Learning Specialization》（Coursera） | 最经典入门，中文字幕，重概念 |
| 李宏毅《机器学习》（YouTube/B 站） | 幽默生动，中文授课，紧跟前沿 |
| 《动手学深度学习》（李沐，d2l.ai 免费） | 理论 + PyTorch 代码并重，中文，**强烈推荐** |
| 3Blue1Brown《神经网络》系列（B 站） | 可视化动画讲透反向传播、梯度下降 |

**主线二：练更多项目（巩固动手能力）**

- CIFAR-10 图像分类（彩色 32×32，CNN 进阶练习）
- 波士顿房价 / 泰坦尼克生存预测（结构化数据、Kaggle 入门经典）
- 文本情感分类（NLP 入门，认识词向量和 RNN）

**主线三：进击大模型（前沿方向）**

- 先补 Transformer 基础（《动手学深度学习》第 11 章）
- 用 Hugging Face 跑通一个开源模型（如 Qwen、Llama）
- 学习提示工程（Prompt Engineering）与检索增强（RAG）

**学习方法论（老生常谈但真有用）**

1. **项目驱动**：每学一个概念，立刻写代码验证，别只看书
2. **复现优先**：读论文/教程时，亲手复现一次胜过读十遍
3. **输出倒逼输入**：写博客、做笔记、录视频讲给别人听
4. **拥抱报错**：报错信息是 AI 给你的免费私教
5. **保持节奏**：每天 1 小时 > 周末狂学 10 小时

## 🐛 常见问题

**Q：学完这个教程，我算「会 AI」了吗？**
A：你已经完整走通了「从数据到模型到应用」的闭环，这是绝大多数自称「在学 AI」的人没做到的事。接下来按路线图继续即可。

**Q：需要学数学吗？**
A：深入理解需要（线性代数、微积分、概率论），但入门阶段**不需要先补数学再动手**。边做边补，遇到「梯度」「矩阵乘法」时去查 3Blue1Brown 的视频，效率最高。

**Q：Fashion-MNIST 换了数据集要改哪里？**
A：只需两处：`datasets.MNIST` → `datasets.FashionMNIST`，以及把标签含义从数字换成服装类别名。其余代码一字不改——这正是「流程通用」的体现。
