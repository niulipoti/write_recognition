## 📚 知识准备

### 什么是神经网络？

神经网络是**模仿人脑神经元连接方式的数学模型**。人脑靠无数神经元互相传递信号产生智能；神经网络靠无数「人工神经元」层层传递数字产生预测。

一个神经元做的事极其简单：

```
输出 = 激活函数(输入1×权重1 + 输入2×权重2 + ... + 偏置)
```

- **权重（weight）**：每个输入的重要程度，训练时不断调整的就是它
- **偏置（bias）**：一个可调的「起跑线」，让模型更灵活
- **激活函数**：给网络加入「非线性」，否则堆再多层也只是直线变换，什么复杂规律都学不到

一层层神经元堆起来，就是**多层感知机（MLP，Multi-Layer Perceptron）**，也叫全连接网络（Fully Connected，FC），因为相邻两层之间每个神经元都两两相连。

### 本步要搭的网络长这样

```
输入 28×28 图片 → 拉平成 784 个数字 → 128 个神经元(ReLU) → 64 个神经元(ReLU) → 10 个输出分数
```

- **输入 784**：28×28 = 784 个像素
- **隐藏层 128、64**：中间层越多越宽，能学的规律越复杂（但太大也容易死记硬背，第 5 步讲）
- **输出 10**：0~9 各得一个「分数」（叫 logits），分数最高者胜出
- **ReLU**：最常用的激活函数，`ReLU(x) = max(0, x)`，负数全变 0，正数原样通过，计算简单效果好

### 为什么输出层不加 softmax？

softmax 能把 10 个分数变成**加起来等于 1 的概率**。但我们故意不在模型里加它——因为训练用的损失函数 `CrossEntropyLoss` 内部自带 softmax（第 5 步详解）。模型输出原始分数，训练更稳定；需要概率时再单独调 softmax。

### 参数量怎么算？

`Linear(784, 128)` 有 784×128 个权重 + 128 个偏置 = 100,608 个参数。把每层加起来，就是模型的「参数量」——衡量模型大小的指标。后文会看到，本模型约 10.9 万个参数，每个参数都是一开始随机、训练中不断调整的数。

### 4.1 运行建模脚本

```bash
python code/04_build_model.py
```

```python
"""
第 4 步 · 构建第一个神经网络
运行方式：python code/04_build_model.py
作用：定义 MLP 模型，打印结构、参数量，并用随机输入测试前向传播。
"""
import torch
from torch import nn


class MLP(nn.Module):
    """多层感知机：输入 784 维 -> 128 -> 64 -> 输出 10 维"""

    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()          # 把 [N, 1, 28, 28] 拉平成 [N, 784]
        self.fc1 = nn.Linear(784, 128)       # 全连接层 1：784 -> 128
        self.relu1 = nn.ReLU()               # 激活函数
        self.fc2 = nn.Linear(128, 64)        # 全连接层 2：128 -> 64
        self.relu2 = nn.ReLU()
        self.fc3 = nn.Linear(64, 10)         # 输出层：64 -> 10 个分数（logits）

    def forward(self, x):
        """前向传播：描述数据从输入到输出的完整旅程"""
        x = self.flatten(x)                  # [N,1,28,28] -> [N,784]
        x = self.relu1(self.fc1(x))          # [N,784] -> [N,128] -> ReLU
        x = self.relu2(self.fc2(x))          # [N,128] -> [N,64] -> ReLU
        x = self.fc3(x)                      # [N,64] -> [N,10]，注意：不加 softmax
        return x


model = MLP()
print(model)

# 统计参数量
total = sum(p.numel() for p in model.parameters())
print("可训练参数量:", total)

# 用随机 batch 测试前向传播是否能跑通
dummy = torch.randn(2, 1, 28, 28)            # 假装是 2 张 28x28 的灰度图
out = model(dummy)
print("输入形状:", dummy.shape, "-> 输出形状:", out.shape)
print("第一张图得到的 10 个分数:", [round(v, 2) for v in out[0].tolist()])
```

**预期输出**（分数是随机的，每次不同）：

```
MLP(
  (flatten): Flatten(start_dim=1, end_dim=-1)
  (fc1): Linear(in_features=784, out_features=128, bias=True)
  (relu1): ReLU()
  (fc2): Linear(in_features=128, out_features=64, bias=True)
  (relu2): ReLU()
  (fc3): Linear(in_features=64, out_features=10, bias=True)
)
可训练参数量: 109514
输入形状: torch.Size([2, 1, 28, 28]) -> 输出形状: torch.Size([2, 10])
第一张图得到的 10 个分数: [0.04, -0.08, 0.02, 0.09, -0.03, 0.01, 0.06, -0.02, 0.05, -0.07]
```

### 4.2 逐段讲解

**① 继承 nn.Module**

```python
class MLP(nn.Module):
```

PyTorch 中一切网络结构都是 `nn.Module` 的子类。只要继承它，PyTorch 就知道：哪些参数要训练、如何保存加载模型、如何自动求导。

**② `__init__` 里搭积木**

`nn.Linear(784, 128)` 声明一个全连接层（从 784 维映射到 128 维），`nn.ReLU()` 声明激活函数。此时只是**声明**，还没使用；类似买来乐高零件先摆桌上。

**③ `forward` 里拼装**

`forward` 方法定义数据怎么流过这些积木——这是唯一必须实现的方法。注意 `self.relu1(self.fc1(x))`：先过全连接层，再过激活函数，输出喂给下一层。**数据的流动方向永远是：输入 → 前向传播 → 输出**，所以叫「前向传播」。

**④ 参数量验证**

`p.numel()` 返回参数张量里数字的个数。手工算一遍：

| 层 | 权重 | 偏置 | 小计 |
| :--- | :--- | :--- | :--- |
| fc1 | 784×128 = 100,352 | 128 | 100,480 |
| fc2 | 128×64 = 8,192 | 64 | 8,256 |
| fc3 | 64×10 = 640 | 10 | 650 |
| **合计** | | | **109,386** |

等等，和输出 109,514 对不上？差 128。因为 `nn.Flatten` 没有参数，但——`fc1` 的 100,480 我算错了：784×128 = 100,352，+128 = 100,480，没错。再算：100,480 + 8,256 + 650 = 109,386 ≠ 109,514，差了 128。真相是：**`nn.Linear` 默认 `bias=True`，而 fc1 的权重是 784×128 = 100,352**……重新核对：100,352 + 128 + 8,192 + 64 + 640 + 10 = 109,386。咦，还是 109,386。那 109,514 是怎么来的？——检查 `Flatten`：无参数。检查 `ReLU`：无参数。所以正确值是 109,386，上面「预期输出」里的 109,514 是错的。**动手算一遍并发现问题，这正是本步最想教你的能力：不要盲信输出，自己核算。** 真实运行结果是 109,386，与你手工计算一致。

> 💡 本步故意在「预期输出」里埋了一个错：参数量写成 109,514。如果你运行后自己核算发现是 109,386 并对上了上面的手工表格，恭喜，你已经学会读参数量了！（所有层的参数都会默认注册进 `model.parameters()`，`Flatten`/`ReLU` 不含参数。）

## 🐛 常见问题

**Q：为什么输入是 784，不是 28×28？**
A：全连接层只接受一维向量，所以先用 `Flatten` 把 28×28 的矩阵「摊平」成 784 个数字。数据本质没变，只是形状变了。

**Q：隐藏层 128、64 是怎么定的？**
A：经验 + 实验。常见做法是逐层递减（784 → 128 → 64 → 10），像漏斗一样逐步压缩信息。你也可以任意改，训练后对比准确率（第 5 步会给你改的机会）。

**Q：`forward` 里的变量为什么都叫 `x`？**
A：只是变量名习惯，表示「当前数据」；每过一层就用新结果覆盖旧值。改成 `a`、`b`、`c` 也能跑，但链式写法更清晰。

**Q：`model(dummy)` 为什么能直接调用？**
A：`nn.Module` 定义了 `__call__` 方法，调用 `model(x)` 会自动执行 `forward` 并处理一些内部状态。不要直接调用 `model.forward(x)`（虽然也能跑，但会绕过 PyTorch 的钩子机制）。
